It started with learning NumPy, pandas and Matplotlib separately and then using them together on real datasets.

## Contents

- NumPy concepts and practice
- pandas concepts and practice
- Matplotlib concepts and practice
- Dataset analysis notebooks
- EDA projects

## EDA projects

- Corona pandemic analysis
- Diwali sales analysis
- Netflix analysis

There are also smaller analysis notebooks covering student, employee and sales datasets.

Python, NumPy, pandas, Matplotlib, Jupyter Notebook

This is a learning-focused repository, so it includes both practice work and projects. I am continuing to add more complete EDA projects as I improve my data-analysis skills.
